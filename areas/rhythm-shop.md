# Rhythm Shop

Two standalone HTML rhythm/pattern games:
- **Freeplay** — single-instrument randomized 32-step pattern generator.
- **Round Robin** — turn-based layered rhythm builder with A/B song-form arrangement.

- Repo: https://github.com/beardsservices-png/Rhythm-Maker.git
- Plan: productionize (separate HTML/CSS/JS, add save/load patterns) and deploy to Railway with a mounted data volume for storage.
